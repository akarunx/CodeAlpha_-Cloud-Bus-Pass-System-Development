🚌 Cloud-Based Bus Pass System ☁️

### 🛡️ Secure | ⚡ Scalable | 🤖 Automated

The **Cloud-Based Bus Pass System** is a high-performance digital ticketing platform designed to replace traditional manual pass issuance with a scalable, secure, and automated cloud-native solution. Built using the **MERN Stack** (MongoDB, Express, React, and Node.js), the system addresses critical transport challenges such as **ticket loss**, **unauthorized duplication**, and **pricing inconsistencies**.

---

## 🚀 Key Features
* **🎫 Digital Pass Generation:** Instant generation of unique bus passes with automated pricing logic.
* **🔐 Anti-Theft Security:** Unique identifiers for every ticket to prevent fraud and ticket loss.
* **☁️ Cloud Integration:** Powered by **MongoDB Atlas** for 24/7 data availability and persistence.
* **📈 High Scalability:** Built with a decoupled architecture to handle high-traffic student commuting hours.
* **📱 Responsive UI:** A modern React-based interface for seamless booking on any device.

---

## 🛠️ Tech Stack
| Layer | Technology | Role |
| :--- | :--- | :--- |
| **Frontend** | **React.js** ⚛️ | User Interface & Booking Form |

## 🏁 Getting Started

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/your-username/bus-pass-system.git
    ```
2.  **Setup Backend:**
    * Navigate to `/server`, create a `.env` file, and add your `MONGO_URI`.
    * Run `npm install` and `node server.js`.
3.  **Setup Frontend:**
    * Navigate to `/client`.
    * Run `npm install` and `npm start`.
